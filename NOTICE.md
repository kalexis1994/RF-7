# Notices

RF-7 is an independent RackForge plugin implemented in Rust and distributed
under GPL-3.0-only.

RF-7 and RackForge are separate software components. The plugin package
contains only RF-7-owned runtime code, metadata, interface resources and the
license/notice files included in this repository.

RF-7 ships no voice data from any other instrument. Its factory voices were
written for RF-7; its model was built from documented behaviour, the published
firmware disassembly and measurements, and it reads the cartridge files its
user already owns. The Yamaha DX7 is a trademark of Yamaha Corporation, which
has no connection with this project.
